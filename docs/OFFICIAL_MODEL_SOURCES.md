# Official BMW source notes

The new detail-page prose summarises public BMW descriptions in original language; the numeric data refer to the specific named reference variants and are not interchangeable with the example Garage model pricing.

All provided BMW / BMW M / BMW regional-channel videos now play **inside the model-details page** using a privacy-enhanced embedded player. They are not copied into the ZIP. The exact short clips from the BMW regional product website were not available as verified third-party embeddable source files and **are not claimed to be identical** to these channel films. The built-in film supports a verified licensed BMW-hosted MP4 if the asset becomes available. For correct streaming, use VS Code Live Server or `START_WEBSITE_WINDOWS.bat`, not a `file:///` address.
